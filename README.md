# 🧮 Advanced Calculator

![C++](https://img.shields.io/badge/Language-C%2B%2B-blue?style=for-the-badge&logo=c%2B%2B)
![OOP](https://img.shields.io/badge/OOP-Implemented-green?style=for-the-badge)
![STL](https://img.shields.io/badge/STL-Used-orange?style=for-the-badge)

A console-based C++ scientific calculator with a menu-driven interface, covering arithmetic, matrices, statistics, calculus, equation solving, number conversions, and expression parsing.

---

## 🚀 Features

| Category        | Operations                                                       |
| --------------- | ---------------------------------------------------------------- |
| 🔢 Basic        | Arithmetic, square, cube, √, factorial                           |
| 📐 Trigonometry | sin, cos, tan, cot, sec, cosec                                   |
| 📊 Logarithms   | log₁₀, ln                                                        |
| 📈 Statistics   | Mean, variance                                                   |
| 🧮 Matrix       | Add, subtract, multiply, divide, transpose, inverse, determinant |
| 🔄 Conversion   | Binary, decimal, hexadecimal, octal                              |
| 🧠 Expression   | Parentheses and precedence via stack evaluation                  |
| 📉 Equations    | Linear and quadratic                                             |
| ∫ Calculus      | Numerical differentiation and integration                        |
| 💾 Utilities    | Memory functions, prime checker, history (`history.txt`)         |

```text

```

---

## 💻 Tech & Concepts

* **C++** with **OOP** (all functionality encapsulated in a `Calculator` class)
* **STL** (vectors, stacks) for data handling and expression evaluation
* **File handling** for saving calculation history
* **Modular design**: one function per operation
