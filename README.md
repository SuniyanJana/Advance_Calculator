A console-based C++ scientific calculator with a menu-driven interface for arithmetic, matrices, statistics, calculus, equation solving, number conversions, and expression parsing.

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>

# Compile
g++ main.cpp -o calculator

# Run
./calculator        # Linux / macOS
calculator.exe      # Windows
```

---

## ✨ Features

> 👇 Click a category to expand it

<details>
<summary>🔢 <b>Basic & Scientific</b></summary>

- Addition, subtraction, multiplication, division
- Square, cube, square root, factorial
- Trigonometry: sin, cos, tan, cot, sec, cosec
- Logarithms: log₁₀, ln

</details>

<details>
<summary>🧮 <b>Matrices</b></summary>

- Add, subtract, multiply, divide
- Transpose, inverse, determinant

</details>

<details>
<summary>📊 <b>Statistics & Equations</b></summary>

- Mean and variance
- Linear and quadratic equation solving

</details>

<details>
<summary>📈 <b>Calculus</b></summary>

- Numerical differentiation
- Numerical integration

</details>

<details>
<summary>🧠 <b>Expression Parser</b></summary>

- Handles parentheses and operator precedence
- Uses a stack-based evaluation algorithm

</details>

<details>
<summary>🔄 <b>Utilities</b></summary>

- Number conversion: binary, decimal, hexadecimal, octal
- Memory functions: add, recall, clear
- Prime number checker
- Calculation history saved to `history.txt`

</details>

## 💻 Tech

| Concept           | Usage                                          |
| ----------------- | ---------------------------------------------- |
